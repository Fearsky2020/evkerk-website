# 青少年主日学 104 课 · V7R 总纲

受众：14–18 岁  
周期：两年 / 104 周  
课堂：默认 55–60 分钟  
语言：中文主讲 + 荷兰语完整对应  
主线：创造 → 堕落 → 应许 → 出埃及 → 神同在 → 王与先知 → 弥赛亚 → 十字架与复活 → 教会 → 新创造

> `RECOVERED` = 从旧 V7 对话中明确找回的决定；`RECONSTRUCTED` = 根据旧骨架、圣经叙事和 V7 规则重新规划，不冒充旧文件原文。

## 第一单元：起初、身份与破裂（1–6）

1. **世界不是偶然的** — 创世记 1 — 创造、秩序、受造世界是礼物。 `RECONSTRUCTED`
2. **我是谁，不由点赞决定** — 创世记 1:26–31；2章 — 神的形象、尊严、身份。 `RECONSTRUCTED`
3. **躲起来以后，神仍来寻找** — 创世记 3 — 羞耻、逃避、神主动寻找与救赎应许。 `RECONSTRUCTED`（旧 V7 曾因让学生扮演神而返工；本版禁止）
4. **嫉妒生气的时候，我会怎么做？** — 创世记 4:1–16 — 该隐与亚伯、愤怒、责任、怜悯。 `RECONSTRUCTED`
5. **在混乱的世界里忠心** — 创世记 6–9 — 挪亚、审判、拯救与约。 `RECONSTRUCTED`（不得编造“众人嘲笑挪亚”）
6. **为什么我们这么想出名？** — 创世记 11:1–9 — 巴别塔、控制、名声与人的边界。 `RECONSTRUCTED`
