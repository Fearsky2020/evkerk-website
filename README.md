# EVKERK Website

New website for 基督教福音教会 / Evangeliekerk.

## v0.1 goals
- Mobile-first public homepage
- Chinese / Dutch language switch
- Light / dark theme
- Clear Sunday gathering information for Rijswijk and Zoetermeer
- First-visit guidance
- Sermons, events, groups and ministries structure
- Cloudflare-ready static deployment

## Source of truth
GitHub `main` is the source of truth. Production domain target: `evkerk.nl`.

## Content policy
Legacy contact details are not copied automatically. Confirm current public phone/email before publishing them on the new site.
